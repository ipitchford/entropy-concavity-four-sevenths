# The critical signal fraction for local entropy concavity

**Gaussian noise restores mixing-weight entropy concavity near the Gaussian exactly below signal fraction 4/7.**

Unrefereed research release, version 0.1.0-candidate (3 November 2026). Author: Anonymous.
Text CC0-1.0; code MIT (see [LICENSE.md](LICENSE.md)).

## The question, in plain terms

Take two independent copies of a random signal, add Gaussian noise to each, and mix the two noisy copies with
weights sqrt(t) and sqrt(1-t). Is the entropy of the mixture a concave function of the mixing weight t?
Ball, Nayar and Tkocz conjectured "yes" for log-concave signals. Luo (2026) disproved this, and showed that
symmetric counterexamples close to the Gaussian survive added noise whenever the signal is more than 4/7 of the
total variance. Below 1/2 a positive local result was known (Schubr 2026). The range 1/2 <= q <= 4/7 was open.

## What this release proves

Write q for the signal fraction (q = Var X / (Var X + noise variance)).

| Result | Statement (informal) |
|---|---|
| Theorem A | For every q < 4/7 there is an explicit neighbourhood of the Gaussian (uniform bound on f/phi - 1) in which every symmetric variance-one input gives a strictly concave entropy curve. |
| Corollary | With Luo's counterexamples: the supremum of such signal fractions is exactly 4/7 (signal-to-noise ratio 4/3). Whether q = 4/7 itself qualifies is open. |
| Theorem B | For every q in (4/7, 1], one sequence of smooth strongly log-concave near-Gaussian inputs makes equal weighting a strict local entropy minimum, with exact curvature constant gamma(q) = 21 sqrt5 q / (49q - 4) and a Gaussian-shaped local profile. The sign on (4/7, 2 - sqrt2] (Luo's Problem 10.3) was also proposed in an earlier public, unrefereed argument (GitHub issue, 1 Nov 2026), which is cited. |
| Proposition S | The Gaussian-smoothing inequality behind Theorem A holds exactly in the range s < b(r) = sqrt(2r(1+r)) - r; it fails beyond. 4/7 is the fixed point q = b(q/2), and within the Hermite test family the extremal member is Luo's counterexample family. |
| Proposition E | At q = 4/7, Luo's family is strictly concave near equal weighting, so it gives no midpoint counterexample at the boundary. |
| Remark R | The proof's radius shrinks like (4/7 - Q)^(9/4). |

The effects are minute (entropy dips of order 1e-13 nats in the constructions); the results are structural.

## Reproduce the checks

Standard-library Python only (tested with CPython 3.12 via uv). From this directory:

    cd checks && python3 -I -B coefficient_checks.py --output-dir results/normal/coefficient_checks
    cd checks && python3 -I -B local_positive_checks.py --output-dir results/normal/local_positive_checks
    cd checks && python3 -I -B identity_checks.py --output-dir results/normal/identity_checks
    cd checks && python3 -I -B extension_checks.py --output-dir results/normal/extension_checks
    cd checks && python3 -I -B negative_controls.py

Add `-O` to run the optimized replay (outputs in results/optimized/). Every checker exits non-zero if any check
fails, including under `-O`. Total runtime is under 30 seconds.
